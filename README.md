\# Tattoo Manager



Aplicativo móvel para auxiliar na gestão de um estúdio de tatuagem, permitindo controlar clientes, agendamentos, orçamentos, produtos, lotes e movimentações de estoque.



\## Tecnologias previstas



\### Aplicativo



\- Android nativo

\- Java

\- XML

\- Material Components

\- Room/SQLite

\- Retrofit



\### Back-end



\- Java 21

\- Spring Boot

\- Spring Data JPA

\- Spring Security

\- Flyway

\- PostgreSQL



\### Ferramentas



\- Android Studio

\- Git e GitHub

\- pgAdmin

\- Postman

\- Figma

\- Gradle



\## Estrutura do repositório



\- `mobile`: aplicativo Android.

\- `backend`: API Spring Boot.

\- `database`: scripts auxiliares e documentação do banco.

\- `docs`: requisitos, arquitetura e documentação.

\- `.github`: configurações e modelos do GitHub.
